Решил создать простенького ai-агента в сфере медицины. Чтобы консультировал меня, ставил диагнозы и прочее. Более конкретно, что он должен делать, пока без понятия.

1. Интерфейс:<br>
Обычно простые программы реализуют общение через телеграм-бота. Я решил реализовать через браузер. Конкретно через FastAPI. В веб-разработке кроме языка HTML ничего не знаю, потому разработку index.html , установку полностью сделал в deepseek.com .

2. LLM-модель:<br>
Тут долго не думал. Во-первых только отечественные, чтобы не иметь проблем с доступом. Из отечественных на слуху только модели от Сбера и Яндекс. Прочитал, что модели от Сбера обучались на медика, потому выбор пал на него. Конкретно GigaChat 2 Lite поскольку поддерживает Function Calling и с наибольшим количеством предоставляемых токенов. В дальнейшем можно поменять на GigaChat 2 Pro . Самый производительный GigaChat 2 MAX.

Чтобы иметь доступ к LLM-моделям от Сбера, необходимо зарегистрироваться на их <a href="https://developers.sber.ru/">сайте</a>, получить ключ Authorization key и сертификат.

Сертификат получил командой:<br>
<code>curl -k "https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt" -w "\n" >> $(python -m certifi)</code>

**Файловая система проекта**<br>
 Корневая папка проекта - ai_doctor
 
 Папка database - в ней файл db.py , содержащий функции для сохранения сообщений в бд, чтения бд. Также когда создавал бд, использовал скрипты, их тоже поместил в эту папку.

Папка templates. В ней файл index.html - лицо моей программы.

Папка routers содержит единственный файл endpoints.py c схемой и роутерами.

В корневой папке три файла: main.py , tools.py и .env .<br>
В tools.py функции для llm-модели, их описание и словарь функций.<br>
.env - секретные переменные: GIGACHAT_AUTH_KEY, DB_PASSWORD, DB_USER, PATH_CATALOG и SYSTEM_PROMPT.<br>
main.py - файл для запуска программы.


### Запуск программы ###
В Терминале входим в папку проекта и выполняем команду:
<code>uvicorn main:app --reload</code><br>
или обычный способ (для Linux):<br>
<code>python3 main.py</code>

В браузере открываем: http://127.0.0.1:8000/<br>
Открывается index.html.

### Создание базы данных ###
Понял, чтобы llm-модель помнила, что она раньше говорила, требуется база данных. У меня уже был создан в docker контейнер с сервером PostgreSQL, поэтому создал базу данных на его основе. Для этого использовал DBeaver - клиент SQL. В нем создал базу данных и таблицы.
<pre>
CREATE DATABASE db_health;
</pre>

Таблицы: CREATE TABLE ...<br>
Запросы поместил в sql/health.sql

Первоначально два excel - файла, данные с них поместить в бд. Для этого написал скрипт load_analiz_db.py , который служит для переноса результатов анализов из Analiz.xlsx в таблицу lab_analiz . Скрипт load_metrics_db.py служит для переноса данных из Показатели.xlsx в таблицу metrics . Эти скрипты также разместил в папке sql. В дальнейшем от идеи размещения данных с локальных файлов в бд отказался. Не вижу в этом смысла.

По итогу получился скорее не агент, а локальный чат, аналог deepseek.com .
